Đồng bộ Power BI (Light Executive + Fix UTF-8 Tiếng Việt)

1. Khi mở test.pbip, bấm nút Refresh trên thanh Home để Power Query M (FixedUtf8) nạp dữ liệu tiếng Việt chuẩn UTF-8 từ Trino.
2. Sau khi chạy crawl thêm các tỉnh mới vào Gold Iceberg, chỉ cần bấm Refresh một lần là toàn bộ 4 trang tự động mở rộng theo dữ liệu mới.
3. Cuối cùng chọn File → Save as → Power BI Report (*.pbix) để lưu lại bản sạch kèm cache tiếng Việt mới nhất.

Media Score = LOG10(1 + SUM('gold_obt_place_360_profile'[total_youtube_views]))
